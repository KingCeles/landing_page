# Re:Zero - Starting Life in Another World | Landing Page

A responsive landing page inspired by the anime series *Re:Zero - Starting Life in Another World*. Built with modern, semantic HTML5 and vanilla CSS, featuring balanced Flexbox layouts, styled typography, and character showcase components.

## ✨ Features

- **Hero Section:** Balanced two-column 50/50 split layout highlighting the premise of the anime with a call-to-action button.
- **Character Showcase:** Uniform card component gallery ensuring all character portraits maintain identical aspect ratios using `object-fit: cover`.
- **Quote Section:** Styled highlight block with right-aligned author attribution (`- Natsuki Subaru`).
- **Clean Navigation:** Minimalist header navigation bar with styled anchor links.
- **Typography:** Integrated Google Fonts (`Roboto`) with responsive weight and size scaling.

---

## 🛠️ Built With

- **HTML5:** Semantic document structuring (`<header>`, `<div class>`, `<img>`, `<button>`).
- **CSS3:** Custom styles utilizing Flexbox layout models (`flex: 1 1 0`, `align-items`, `justify-content`), custom color palettes, and CSS resets.
- **Google Fonts:** Roboto font family.
